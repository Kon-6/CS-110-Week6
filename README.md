# CS-110-Week6 C# project

This week I learned the basics of C# and how to make a console app.My program asks the user for their name and stores it in a variable. It then uses the name to display a message letting the user know that the C# console app is running.I also learned how Console.WriteLine() displays information and Console.ReadLine() gets input from the user.

## Testing
I tested my program using dotnet run in the terminal. I entered my name and the program displayed: 
Hello, Kevin! Your C# console app is running.
